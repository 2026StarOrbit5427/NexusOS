- 功能说明
- **启动链路**：开机动画 7 阶段 / 10 秒 → 淡出 → 锁屏（可设 4–6 位密码）→ 首次设置向导 11 步
- **桌面**：5 场景（在家 / 通勤 / 办公 / 运动 / 夜间）+ 自动巡航；双指捏合进编辑，双指张开切场景
- **负一屏**：桌面右滑进入，24 个工具（手电筒、扫一扫、计算器、计时器、秒表、指南针、水平仪、单位/汇率换算、翻译、垃圾清理…），小组件可勾选
- **控制中心**：12 磁贴，与设置 / 负一屏快捷开关双向同步
- **系统更新**：1.0.4 更新历史 4 个版本；三点菜单含夜间自动更新与 5 GB / 50 秒完整包（数据不清除，结束显示欢迎回来，上滑或输密码进桌面）
- **恢复出厂**：5 次警告，清空全部本机数据并重新进入首次设置向导
- **显示效果**：深色模式（关闭 / 日落到日出 / 自定义时段）、护眼三档、亮度、液态玻璃
- **声音与震动**：来电·提醒·通知 / 闹钟 / 音乐·游戏·媒体 三条音量，8 款铃声，5 个震动开关
- **小星同学**：自动（免 Key）/ 自定义（DeepSeek / Kimi / 智谱 / 硅基流动 / OpenAI / Ollama）/ 仅本地，系统指令本地优先
- **天气**：Open-Meteo + 浏览器定位 / IP 定位 / 手动城市，离线显示「无实时数据」
- **SIM**：APK 读真实运营商 / 制式 / 双卡；网页版如实降级
- **应用**：30+ 个，含应用商店 8 款第三方、手机管家 10 项、40 首音乐
- **三语**：简体中文 / 繁體中文 / English，运行时即时切换
- **适配**：16 种视口，平板与桌面居中手机框，刘海与手势条安全区
